## While, until, select

Different ways to use while loops and until loop:

**Syntax**

```bash
while [ condition ]
do
    command1
    command2
done

# ---

until [ condition ]
do
    command1
    command2
done

```

Until - condition --> false, keep executing, as soon the condition become true, come out from until loop

## SSH Protocol

using mstsc we can login from 1 windows server to another, we can use mstsc.

Since we are using the servers from AWS cloud, by default AWS will disable the password authentication. as well root login also disabled.

```bash
# ssh configuration file
$ sudo vi /etc/ssh/sshd_config

# Inside the file under the Authentication section

# Authentication
PermitRootLogin yes
PasswordAuthentication yes

$ systemctl reload sshd
$ systemctl restart sshd
$ systemctl status sshd

```

## 2 Server are there

Centos and Aws Linux :

**Centos**

In Centos Server the ip is : <Centos_Server_IP>

we need to enable the password authentication as well enable the root login, so we need to change the /etc/ssh/sshd_config

```bash
# ssh configuration file
$ sudo vi /etc/ssh/sshd_config

# Inside the file under the Authentication section

# Authentication
PermitRootLogin yes
PasswordAuthentication yes

$ systemctl restart sshd

# Add a new password
$ passwd

```

**AWS Linux**

In AWS Linux Server the ip is : <AWS_Linux_IP>

we need to enable the password authentication as well enable the root login, so we need to change the /etc/ssh/sshd_config

```bash
# ssh configuration file
$ sudo vi /etc/ssh/sshd_config

# Inside the file under the Authentication section

# Authentication
PermitRootLogin yes
PasswordAuthentication yes

$ systemctl restart sshd
```

Then to connect the aws Linux server to Centos Server. In the Linux terminal

```bash
$ ssh root@<Centos_Server_IP>

```

Different between adduser and useradd

```bash
# Give full user info. It will make your like simpler
$ adduser badhon

# Manual need to add the user
$ useradd badhon
```

To stop a particular user or root login user we need to config the /etc/ssh/sshd_config

```bash
$ adduser badhon # Add information
$ vim /etc/ssh/sshd_config

# Enable PasswordAuthentication to true
PasswordAuthentication yes
# PermitRootLogin yes

# Add the line to deny a particular user
DenyUsers badhon


# Allow only user to login to the system
AllowUsers badhon118

```

## PasswordLess Authentication

**Server 1 : Main Server**

```bash
$ ssh-keygen

# Content we need to copy to the remote server (Staging Server)
#  /root/.ssh/authorized_keys

# We need to go to the .ssh folder
$ cd .ssh

# It will ask the password just for one time
# Note : If it was a cloud server then we need to config the /etc/ssh/sshd_config file then we will be able to do this
$ ssh-copy-id <username>@<Server_IP>

# It will automatically login to the remote server
$ ssh <username>@<Server_IP>
```
